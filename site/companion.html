Won't this get me banned?

No. Executors like Xeno or Velocity get you banned because they inject code into the running game. The companion never touches the game at all.

Only reads a log file

Roblox writes a plain text log to %LOCALAPPDATA%\Roblox\logs on every PC. The companion reads it, just like Fishstrap and Bloxstrap do to show your server location.

Its own window

It's a separate window that floats on top. It doesn't draw inside Roblox, read Roblox's memory or attach to its process.

Official join links

Rejoin and server hop use the same roblox:// links as the Join buttons on roblox.com.

No login, no cookies

It only uses Roblox's public website data (game name, server list). It never reads your account or browser.

Set up with Fishstrap or Bloxstrap

So it opens when Roblox opens and closes when Roblox closes.

  1. Download the companion and put it somewhere it can stay, like Documents\Bloxboard\BloxboardCompanion.exe.
  2. Open Fishstrap (or Bloxstrap) → Integrations → Custom Integrations → New.
  3. Name: Bloxboard Companion. Application location: the .exe you saved. Launch arguments: --with-roblox.
  4. Turn on Auto close when Roblox closes, save, and launch Roblox.

Windows says "Windows protected your PC"? That's SmartScreen being careful with new apps that aren't signed by a big company. Click More info → Run anyway. You only have to do this once.

No Fishstrap? Just open the .exe yourself: it waits in the tray until you join a game.

# Bloxboard

Free Roblox companion extension (Chromium / Helium): server browser with regions, player finder,
playtime, trade values, friends, and a dashboard. Website: https://bloxboard.enesserver.dev

## Why Bloxboard?
**Ever get tired of the features you need sitting behind a paywall?**
Well, we don't do that! All of our features are free to use!
We know the struggles of trying to find a free copy, all for a few minor quality of life additions.

## Is it safe?
**Yes!**
It is safe, and if you don'tt believe us, check the source code. It is fully open sourced.
